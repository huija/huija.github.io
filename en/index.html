skillmod

go mod for Agent Skills

A skill dependency manager for agent projects. Declare dependencies in SKILL.mod, pin content in SKILL.lock, and let skillmod sync make every machine byte-identical. Share installs with any agent, and use verify as a ready-made CI gate. In the spirit of Go modules: sources straight from Git, publishing is tagging, no server, no registry.
