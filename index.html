skillmod

go mod for Agent Skills

面向 agent 项目的 skill 依赖管理器。SKILL.mod 声明依赖，SKILL.lock 内容寻址锁定，sync 让每台机器逐字节一致，share 把同一套安装分发给任意 agent，verify 是现成的 CI 关卡。设计血统来自 go mod：直接走 Git 源，打 tag 即发布，无服务端、无 registry。

Go CLI Agent 依赖管理 CI 关卡
$ skillmod get github.com/openai/skills//gh-fix-ci
$ skillmod share --all --agent claude --agent workbuddy
